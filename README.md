48 tools for design work, grouped by the stage: drawing the interface, getting it into code,
building a brand around it, choosing colour and type, making the illustration, animating it,
modelling it in three dimensions, testing it, diagramming it, and presenting it.

One sentence decides what is here: a picture is an output, and the work is the file somebody
can open next. Tools that return a flattened image where a component, a vector, or a
prototype is needed are not design tools, however good the output looks.

Maintained by [TiorAI](https://tiorai.com/), which catalogues AI tools for a living.

## Interface design

The canvas an interface is drawn on, and what it produces for the next person.

- **[Creatie](https://creatie.ai/)** — Generation built into the canvas, aimed at teams migrating from a file-based tool. `Freemium` `Web` `Windows` `macOS`
- **[Figma](https://www.figma.com/)** — Where the design system lives, and the format a contractor expects to receive. `Freemium` `Web` `Windows` `macOS`
- **[Lunacy](https://icons8.com/lunacy)** — Runs offline and opens Sketch files, which is a narrow need nothing else covers. `Freemium` `Windows` `macOS` `Linux`
- **[Motiff](https://www.motiff.com/)** — Detects where a screen departs from the design system rather than only rendering it. `Freemium` `Web` `Windows` `macOS`
- **[Penpot](https://penpot.app/)** — Self-hostable and open format, so the files do not depend on a company continuing to exist. `Open Source` `Web` `Linux`
- **[Stitch](https://stitch.withgoogle.com/)** — Generates a screen from a description and exports it into a design file, not an image. `Freemium` `Web`
- **[Uizard](https://uizard.io/)** — Converts a sketch or a screenshot into editable layers rather than a flat trace. `Freemium` `Web`
- **[Visily](https://www.visily.ai/)** — Aimed at people who are not designers but have to produce a wireframe anyway. `Freemium` `Web`

## Design to code

Getting a layout out of the design tool and into a repository.

- **[Anima](https://www.animaapp.com/)** — Exports design files as components that use your own tokens rather than absolute values. `Freemium` `Web`
- **[Builder.io](https://www.builder.io/)** — Converts a design into a component and keeps it editable by non-developers afterwards. `Freemium` `Web` `API`
- **[Framer](https://www.framer.com/)** — The design file is the published site, which removes the handoff step entirely. `Freemium` `Web`
- **[Locofy](https://www.locofy.ai/)** — Tags a design's interactive elements first, so the generated code is not one flat block. `Freemium` `Web`
- **[Magic Patterns](https://www.magicpatterns.com/)** — Starts from a written description rather than from a file, which suits an idea with no mockup. `Freemium` `Web`
- **[Relume](https://www.relume.ai/)** — Produces the sitemap and wireframes a site needs before anybody opens a design tool. `Freemium` `Web`

## Brand identity

A mark, a system around it, and the files a printer will accept.

- **[Kittl](https://www.kittl.com/)** — Strong on lettering and badge work, which is where generic generators are weakest. `Freemium` `Web`
- **[Looka](https://looka.com/)** — Delivers the whole kit with export formats, which is what a non-designer actually needs. `Freemium` `Web`
- **[Recraft](https://www.recraft.ai/)** — Generates true vector output and holds one style across a whole set of assets. `Freemium` `Web`
- **[Vectorizer.AI](https://vectorizer.ai/)** — Traces a raster mark into clean curves, which is the step between generated and printable. `Freemium` `Web` `API`

## Colour and typography

The two decisions that make everything else look considered or not.

- **[Coolors](https://coolors.co/)** — Generates palettes with contrast checking attached, so an accessible choice is visible. `Freemium` `Web` `iOS` `Android` `Browser Extension`
- **[Fontjoy](https://fontjoy.com/)** — Pairs typefaces by how different they are, which is the pairing problem stated correctly. `Free` `Web`
- **[Fontshare](https://www.fontshare.com/)** — Free commercial-use typefaces from a foundry, rather than a directory of uncertain licences. `Free` `Web`
- **[Huemint](https://huemint.com/)** — Generates palettes for a specific layout, so the colours are assigned rather than listed. `Free` `Web`
- **[Khroma](https://www.khroma.co/)** — Trains on colours you said you liked and then only shows you those. `Free` `Web`

## Illustration and vectors

Editable artwork rather than a picture of artwork.

- **[Adobe Firefly](https://firefly.adobe.com/)** — Trained on licensed stock, which is the reason agencies can put it in a client deliverable. `Freemium` `Web`
- **[Freepik](https://www.freepik.com/)** — A stock library with generation beside it, so a near-match can be adjusted rather than redone. `Freemium` `Web`
- **[Illustroke](https://illustroke.com/)** — Produces SVG illustrations from a description, in a consistent set of styles. `Paid` `Web`
- **[Krea](https://www.krea.ai/)** — Real-time canvas where a rough shape becomes artwork as you keep drawing it. `Freemium` `Web`

## Motion and animation

Interface motion, and the file formats that ship it.

- **[Jitter](https://jitter.video/)** — Animates a design file directly, which suits a designer rather than a motion specialist. `Freemium` `Web`
- **[LottieFiles](https://lottiefiles.com/)** — The format most apps ship animation in, with the tooling and library around it. `Freemium` `Web` `iOS` `Android` `API`
- **[Phase](https://phase.com/)** — Timeline animation with a designer's interface rather than a video editor's. `Freemium` `Web`
- **[Rive](https://rive.app/)** — State machines rather than clips, so the animation responds to what the app is doing. `Freemium` `Web` `Windows` `macOS` `API`

## 3D and product visualisation

Objects and scenes, for people who are designers rather than modellers.

- **[Spline](https://spline.design/)** — Builds 3D scenes that embed in a web page and respond to a scroll or a cursor. `Freemium` `Web` `Windows` `macOS`
- **[Vectary](https://www.vectary.com/)** — Runs in the browser and publishes an embeddable configurator without a plugin. `Freemium` `Web`
- **[Vizcom](https://vizcom.com/)** — Turns an industrial-design sketch into a rendered concept while keeping the drawn lines. `Freemium` `Web`
- **[Womp](https://womp.com/)** — Modelling simple enough for a graphic designer who has never opened a 3D tool. `Freemium` `Web`

## Design research and testing

Finding out whether the design works before it ships.

- **[Attention Insight](https://attentioninsight.com/)** — Predicts where attention lands on a design before it has been shown to anyone. `Paid` `Web`
- **[Maze](https://maze.co/)** — Tests a prototype unmoderated and reports the click path people actually took. `Freemium` `Web`
- **[Useberry](https://www.useberry.com/)** — Tests across prototypes and live sites in one study, which most tools separate. `Freemium` `Web`
- **[UXtweak](https://www.uxtweak.com/)** — Covers card sorting and tree testing, which is where information architecture is decided. `Freemium` `Web`

## Diagrams and whiteboards

Explaining a decision to somebody who was not in the room.

- **[Eraser](https://www.eraser.io/)** — Diagrams written as text and rendered, so they live in a repository beside the code. `Freemium` `Web`
- **[Excalidraw](https://excalidraw.com/)** — Deliberately rough, which stops a sketch being read as a finished proposal. `Open Source` `Web`
- **[Miro](https://miro.com/)** — The board a workshop happens on, with clustering and summarising over the sticky notes. `Freemium` `Web` `Windows` `macOS` `iOS` `Android`
- **[Napkin](https://www.napkin.ai/)** — Reads a paragraph and proposes the diagram that would replace it. `Freemium` `Web`
- **[Whimsical](https://whimsical.com/)** — Flowcharts and wireframes in one file, which is how a feature actually gets sketched. `Freemium` `Web`

## Presentation design

The deck, which is the format most design decisions are actually explained in.

- **[Adobe Express](https://www.adobe.com/express/)** — Brand kits applied across every asset a campaign needs, decks included. `Freemium` `Web` `iOS` `Android`
- **[Beautiful.ai](https://www.beautiful.ai/)** — Slides that re-lay themselves as content is added, so alignment never drifts. `Paid` `Web`
- **[Canva](https://www.canva.com/)** — Where a non-designer produces something presentable without a brief or a budget. `Freemium` `Web` `Windows` `macOS` `iOS` `Android`
- **[Gamma](https://gamma.app/)** — Generates a deck as a responsive document rather than as fixed-size slides. `Freemium` `Web`

## How tools are selected

A tool qualifies when it produces something **editable and reusable**: a component, a
prototype, a palette, a vector file, an animation rig, a test result, or a diagram somebody
else can change. It has to serve design work rather than decorate it.

### The rule that does most of the work here

**A picture is an output; the work is the file somebody can open next.** That sentence decides
almost every inclusion here, and it is what separates this list from `awesome-ai-image-tools`.

A generator that returns a flattened image of a screen has produced a mockup nobody can build
from. A tool that returns layers, components, a vector path, a state machine, or a palette with
contrast values has produced work. Several well-known products sit on the wrong side of that
line and are not here, however good the output looks.

The consequence worth stating: this list is unglamorous in places. Colour, typography, testing,
and diagramming are four categories nobody writes an article about, and they decide more about
whether a design works than the generation categories do.

### What the categories are telling you

The ten groups are stages of design work rather than product categories, and three of them are
there on purpose:

- **Colour and typography** is where a design stops looking amateur, and it is four free tools
  and an afternoon.
- **Design research and testing** is the only group that tells you whether any of the rest
  worked.
- **Diagrams and whiteboards** is included because explaining a design to somebody who was not
  in the room is most of a senior designer's actual job.

Image generation is not here. It is a category of its own and `awesome-ai-image-tools` covers
it; what appears in the illustration group is there because it returns something editable.

### What is excluded

Tools that return a flattened image where a file is needed: screen generators with no export,
logo makers that deliver a raster file only, mockup generators. Stock sites with no generation
or editing of their own. Template marketplaces. Font directories whose licences are unclear,
which is most of them.

General image generation belongs in `awesome-ai-image-tools`, video in `awesome-ai-video-tools`,
and the website builders a non-designer uses in `awesome-ai-tools-for-local-business`. A
product can honestly appear in two of those and this one; where it does, the description here is
written for a designer.

Entries are ordered alphabetically inside each category. Position carries no meaning, and
there is no paid placement, sponsorship, or affiliate link anywhere in this repository.

## Disclaimer

Everything listed is built and operated by a third party, not by TiorAI. Pricing, plan
limits, and terms change without notice, and a tool that fits today may not next quarter.

**Training data and commercial use are not the same question, and only one of them is answered
on a pricing page.** Where a generator's training corpus is licensed, the description says so,
because that is what decides whether the output can go into a client deliverable. Where it is
not stated, this list does not guess, and you should read the terms before invoicing anybody for
what the tool produced.

**File portability outlives the subscription.** Several categories here hold your work in a
proprietary format, and a design file you cannot open in five years is a design you will redraw.
Where an entry is open format or self-hostable the description says so; it is the least
exciting fact about a design tool and the one most likely to matter.

Listing here is editorial selection, not endorsement.
